A GitHub-compatible git forge in a single Node.js process: git smart-HTTP (clone and push, hand-rolled pack protocol), REST v3 (repositories, branches, commits, contents, issues, labels, pull requests and merges), GraphQL v4, and MCP tools — all over one shared in-memory store, standard library only, no git binary and no dependencies. Passes the competition kit's full conformance suite locally (120/120 checks).

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> node main.ts
```
